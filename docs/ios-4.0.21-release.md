# Seguridad y manejo de sesiones

Release candidate: `4.0.21 (249)`.

App Store Connect mostraba `4.0.20` disponible y `248` como la compilación más reciente al preparar este candidato. Verifica el número de compilación inmediatamente antes de subir el archivo.
